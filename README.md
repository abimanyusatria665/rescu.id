# RESCU.ID

Company profile one-page untuk RESCU.ID, dibuat dengan HTML5, CSS3, dan Vanilla JavaScript.

## Menjalankan lokal

Buka `index.html` langsung di browser, atau jalankan static server sederhana:

```bash
python -m http.server 8080
```

Lalu buka `http://localhost:8080`.

## Catatan

- Kontak WhatsApp dan email masih berupa placeholder (`+62 812 3456 7890` dan `hello@rescu.id`).
- Foto menggunakan URL Unsplash agar halaman langsung memiliki visual saat dijalankan.
- Seluruh konten dan interaksi utama berada di `index.html`, `css/style.css`, dan `js/main.js`.
